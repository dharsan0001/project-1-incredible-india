# Incredible India – Nature Travel Gallery

A responsive travel gallery website showcasing beautiful destinations across India.

## Features

- Responsive travel gallery layout
- Destination images
- Featured travel destinations
- Navigation section
- Responsive design for desktop, tablet and mobile
- Footer with developer credit

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## Project Structure

```text
project-1-natural/
├── index.html
├── style.css
├── ans.txt
├── README.md
└── screenshots/
    ├── nature.png
    └── nature mobl.png
```

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
